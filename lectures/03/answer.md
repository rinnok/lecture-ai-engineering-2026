## 宿題

- 取り組んだレベル：基礎 
- やったこと：

 - 実験A：app/agent.py の INSTRUCTIONS から「必ず search_glossary で用語集を確認する」の1行を消した。質問は「AIE2026の講座の宿題にある「3レベル」とは何ですか？」。変更の前後で3回ずつ、--trace 付きで実行した。

 - 実験B：app/tools.py の search_glossary の docstring の「1つだけ入れる」を「まとめて入れる」に変えた。質問は「LoRAとQLoRAの違いは？」。変更の前後で3回ずつ実行した。
  - 変更は一度に1か所だけにした。実験Bの前に、実験Aの変更は元に戻した。


- 結果：
 - 実験A（変更前 → 変更後）
    - tool call：search_glossary('3レベル') が1回で、前後とも同じ
    - tool_calls / requests：1 / 2 のまま変わらなかった
    - 入力トークン：783 → 735
    - 回答：前後とも用語集どおり。変更後は言い回しが少し長く、口調がやわらかくなった
  - 実験B（変更前 → 変更後）
    - tool call：2回（'LoRA'、'QLoRA'）→ 1回（'LoRA QLoRA'）
    - tool_calls / requests：2 / 2 → 1 / 2
    - 入力トークン：1196 → 885
    - 回答：前後とも用語集にもとづく説明だった
  - 変更前の3回は、tool call の呼び方が毎回同じだった。ぶれたのは回答の言い回しだけだった。


- 気づき・疑問：
 事前の予想として実験Aは、検索されなくなり一般論で答えると考えた。実験Bは、tool call が1回になり、検索の中身は別々になると考えた。しかし、予想は外れた。INSTRUCTIONS から「必ず用語集を確認する」の行を消しても、ツールは呼ばれ続け、回答も用語集どおりだった。ツールの docstring にも「答える前に使うこと」と書かれていて、同じ指示が2か所にあったためだと考えた。入力トークンは 783 から 735 に減った。INSTRUCTIONS が1行短くなった分だと考えた。

 実験Bでは、検索を1つずつに分けなくても、LLM が2つの用語を1回の検索（'LoRA QLoRA'）でまとめて扱えたことが予想と違っていた。ツールの呼び出しは2回から1回に減り、入力トークンも 1196 から 885 に減った。ただし、LLM を呼ぶ回数（requests）は2のままだった。トークンが減ったのは、変更前に重複して返っていた検索結果が減ったためだと考えた。1つの質問だけで試したので、まとめれば必ず減るとは言い切れない。

 どうすれば消費トークンが減るのかのヒントを得られた気がする。

 実験Aと実験Bから、エージェントの動きは、処理を書いたコードではなく、モデルが読む日本語の文（INSTRUCTIONS と docstring）で決まっていると考えた。実験Bでは、docstring の1語を「1つだけ」から「まとめて」に変えただけで、ツールの呼び方が変わった。実験Aでは、片方の文を消しても、もう片方に同じ指示があれば、動きは変わらなかった。動きを変えたいときは、同じ内容を言っている文が、ほかにないかも確かめる必要がある。
